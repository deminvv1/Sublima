### Рекомендации
1. **Приоритет для лендингов** — группы 1–3 (горячий коммерческий спрос).
2. **Группа 6** — контент-план для блога: каждая тема = статья, которая приводит органический трафик и греет аудиторию.
3. **Группа 7** — только для рекламных кампаний (Директ), в SEO-тексты бренды конкурентов не вставлять.
4. Частотность проверить в **Яндекс.Вордстате** (wordstat.yandex.ru) по целевому региону; для EN — Google Keyword Planner.
